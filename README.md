# 🛡️ Segurança Digital

Projeto educativo desenvolvido para conscientizar usuários
sobre golpes digitais e formas de prevenção.

## 📌 Sobre o projeto

Este projeto foi realizado para uma atividade de extensão realizada com jovens de uma comunidade,
tivemos um momento presencial para aprender como identificar comportamentos suspeitos e o que fazer para evitar cair em algum golpe digital.

## 🎯 Objetivo

O objetivo é ajudar os usuários a reconhecer possíveis golpes
e aprender boas práticas de segurança digital.

## 💻 Tecnologias utilizadas

- HTML
- CSS
- JavaScript

## 🎮 Funcionalidades

- Quiz sobre golpes digitais
- Cartões interativos
- Perguntas educativas
- Sistema de pontuação
- Mensagens de resultado

## 🚀 Como executar

1. Baixe este repositório.
2. Abra o arquivo index.html.
3. Execute o projeto em um navegador.
